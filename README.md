# Faciter Front-end — Desktop + Mobile

Front-end responsivo baseado na referência enviada.

## Estrutura
- index.html
- style.css
- script.js
- assets/hero.jpg
- assets/compass.jpg
- assets/logo.svg

## Mobile
Em telas de até 900px:
- aparece o botão de menu;
- o menu vira um painel suspenso;
- os botões ficam em largura adequada;
- o hero se adapta à tela;
- os cinco passos passam para uma lista vertical;
- a seção da bússola adapta imagem e conteúdo;
- o footer fica empilhado.

## Como testar
Abra `index.html` no navegador e diminua a janela, ou use as ferramentas de desenvolvedor do navegador para simular um celular.
